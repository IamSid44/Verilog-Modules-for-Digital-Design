# Verilog-Modules-for-Digital-Design

This repo contains HDL (iverilog) scripts for multiple digital logic elements. Originally intended to be submitted as an assignment in the course VLSI Design.

Q1 -> Gates

Q2 -> Logic Functions

Q3 -> MUX, DEMUX, Decoder, Encoder

Q4 -> Adders

Q5 -> Flip FLops

Q6 -> Universal Shift Register

Q7 -> Serial Adder

Q8 -> Counters

Q9 -> Sequential Circuit

Q10 -> Finite State machines

Q11 -> Sequential Circuit
